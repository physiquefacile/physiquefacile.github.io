Labo Virtuel de Physique

Neuf travaux pratiques de mécanique, d'électricité et d'optique : un montage simulé pour faire tes mesures, puis un compte rendu corrigé en ligne. Dr P. T. Traoré.

Comment se déroule un TP

  1. Connecte-toi en haut de la page du TP avec ton numéro de carte et ton code personnel.
  2. Commence le TP : ton minuteur démarre et tu reçois ton propre matériel simulé.
  3. Fais tes mesures, puis remplis le tableau, le graphe et les calculs du compte rendu.
  4. Réponds au QCM, calculé à partir de tes mesures, puis soumets : ta note s'affiche aussitôt.

Installer le labo sur ton téléphone

Une fois installé, le labo s'ouvre comme une application et les TP fonctionnent même sans connexion ; seule la soumission demande internet.

Sur iPhone ou iPad
  1. Ouvre ce site dans Safari (pas depuis WhatsApp ou Facebook : touche « Ouvrir dans Safari »).
  2. Touche le bouton Partager (le carré avec une flèche vers le haut).
  3. Choisis « Sur l'écran d'accueil », puis « Ajouter ».
