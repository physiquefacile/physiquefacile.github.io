# Cours de Physique — Licence 1

Plateforme des cours du **Dr Papa Touty TRAORÉ**, Enseignant-Chercheur à l'Université Souleymane Niang de Matam (UFR Sciences).

- **Physique I — Mécanique du point matériel** : calcul vectoriel, cinématique, dynamique, travail et énergie (supports, diaporamas, TD et corrigés).
- **Électricité — Électrostatique** : charge et loi de Coulomb, champ et potentiel, série de TD n°1.

Le site est publié avec GitHub Pages à partir de la branche `main`.

## Organisation des fichiers
- `index.html` : page d'accueil et liseuse PDF
- `docs/` : supports de cours et séries de TD (PDF)
- `slides/` : diaporamas (PDF)
- `img/` : vignettes des couvertures
