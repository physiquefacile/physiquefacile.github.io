Par où commencer pour réviser un chapitre ?
  1. Relis le support de cours, en refaisant toi-même les démonstrations.
  2. Fais le quiz du chapitre et reprends les sections indiquées pour chaque erreur.
  3. Entraîne-toi avec les exercices à valeurs aléatoires jusqu'à les réussir sans la correction.
  4. Cherche les exercices de TD seul, avant de regarder le corrigé.
Comment bien utiliser un corrigé de TD ?

Cherche d'abord l'exercice au moins vingt minutes. Ensuite, ne lis que l'étape suivante du corrigé, ferme-le et continue seul. Refais l'exercice entier quelques jours plus tard, sans le corrigé : c'est ce qui prépare réellement à l'examen.

Comment utiliser le site sans connexion ?

Ouvre le site une première fois avec internet : les cours, les TD, les quiz, les simulations et les exercices sont alors enregistrés sur ton téléphone. Les diaporamas, plus lourds, s'enregistrent avec le bouton « Enregistrer les diaporamas » de la page d'accueil. Un document enregistré porte une coche ✓.

Comment installer le site comme une application ?

Sur Android (Chrome) : bouton « Installer l'application » sur la page d'accueil, ou menu ⋮ puis « Installer l'application ». Sur iPhone (Safari) : bouton Partager puis « Sur l'écran d'accueil ».

Je ne vois pas les dernières nouveautés.

Ferme complètement le navigateur, puis rouvre le site avec internet. La nouvelle version s'installe automatiquement.

Comment saisir une réponse dans l'entraînement ?

Écris un nombre avec une virgule ou un point (3,6 ou 3.6). Pour les puissances de 10 : 3,6e4 ou 3,6x10^4. Respecte l'unité indiquée à côté de la case. Une erreur de 2 % est tolérée.

L'enseignant voit-il mes scores aux quiz ?

Non. Les scores restent uniquement sur ton téléphone ; ils servent à te situer, pas à te noter.

Un document ne s'ouvre pas.

Vérifie la connexion, puis réessaie. Si la liseuse intégrée ne démarre pas, un bouton propose d'ouvrir le document avec le lecteur PDF du téléphone. Si le problème continue, signale-le avec le formulaire (objet « Problème avec le site »).
